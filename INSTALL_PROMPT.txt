# CachyOS Dotfiles — инструкция для GPT

Ты помогаешь восстановить конфигурацию CachyOS + Hyprland из этого репозитория.

Цель: установить конфиги из репозитория в домашнюю директорию пользователя так, чтобы система снова работала как до переустановки.

Структура репозитория:
config/hypr/       -> ~/.config/hypr/
config/noctalia/   -> ~/.config/noctalia/
config/kitty/      -> ~/.config/kitty/
config/fish/       -> ~/.config/fish/
config/gtk-3.0/    -> ~/.config/gtk-3.0/
config/gtk-4.0/    -> ~/.config/gtk-4.0/
config/qt5ct/      -> ~/.config/qt5ct/
config/qt6ct/      -> ~/.config/qt6ct/
config/xsettingsd/ -> ~/.config/xsettingsd/
config/kdeglobals  -> ~/.config/kdeglobals

ВАЖНО:
1. Не удаляй существующие пользовательские конфиги без резервной копии.
2. Перед копированием создай backup текущего ~/.config.
3. Сначала изучи содержимое репозитория и определи, какие файлы действительно нужны.
4. Не копируй .git, если он присутствует внутри вложенных директорий.
5. Не перезаписывай системные файлы в /etc без явного указания пользователя.
6. Не используй sudo для копирования пользовательских конфигов в ~/.config.
7. После установки проверь права владельца файлов: они должны принадлежать текущему пользователю.
8. Если какого-либо приложения нет в системе, сначала сообщи пользователю, какой пакет требуется установить.
9. Не устанавливай случайные пакеты без объяснения причины.
10. Не трогай браузеры, VPN, пароли, SSH и другие приватные данные, если они отсутствуют в репозитории.

Особенно важно для Hyprland:
- сохранить всю структуру ~/.config/hypr/
- не объединять Lua-конфиги в один файл без необходимости
- сохранить hyprland.lua и директорию config/
- проверить monitors.lua, workspaces.lua, binds.lua, inputs.lua, decorations.lua, colors.lua и windowrules.lua
- после установки проверить конфигурацию Hyprland перед перезапуском
- если конфигурация использует UWSM, Noctalia или другие внешние программы, проверить их наличие

После копирования:
1. Проверить наличие всех директорий и файлов.
2. Проверить владельца файлов.
3. Проверить конфигурацию Hyprland.
4. Проверить, что Noctalia, Kitty и Fish имеют свои конфиги.
5. Сообщить пользователю, какие пакеты/программы отсутствуют.
6. Только после проверки предложить перезапуск Hyprland.

Не выполняй потенциально опасные команды автоматически. Если команда может удалить данные или перезаписать важные файлы, сначала предупреди пользователя.
